# A2 跨集泛化：在 deepset 上调好，到别的语料上还灵吗

> 代码：`injlab/eval/a2.py`（编排）+ `injlab/_a2_one.py`（单检测器打分）+ `injlab/data/transfer.py`（目标集构建）
> 复现：`python -m injlab build-targets && python -m injlab a2`
> 原始数据：`runs/20261101_225453_a2/a2.json`

## 一句话结论

**在源域上调到 0.88 的检测器，一到域外就把 79% 的正常对话判成注入。**
跨集的主要失败模式不是漏检，是**误报爆炸**——它比漏检更难被发现，
因为在你的测试集上它根本不会出现。

## 怎么读这几张表

**1. TPR 掉得很惨，而且不是阈值问题。**
DistilBERT 在源域测试集上 TPR@1% = 0.883（A1），到 ToxicChat 只剩 0.343。
把阈值换成 oracle（在目标域良性上重标）也还是 0.343 —— 说明**不是阈值错位，
是排序本身错了**：模型把域外的正常对话排在了注入前面。

**2. 误报才是真正的杀招。**
DistilBERT 在 ToxicChat 良性上误报 79.2%，在 AEGIS 上误报 75.9%。
也就是说：一个真实用户在客服机器人里随便聊两句，四次里有三次被判成攻击。
这种系统上线第一天就会被关掉。

**3. 现成 guardrail 反而更稳。**
guardrail 的 FDR 只有 4.3%（ToxicChat）和 3.8%（AEGIS），TPR 0.500。
它的绝对召回不高（A1 里就输给字符级 TF-IDF），但**跨域不崩**。
机制上讲得通：它是在大规模安全语料上训的，见过的域外分布比我们多。

**4. 词级 TF-IDF 在 PINT 上误报 100%。**
PINT 只有 8 条（6 良性 2 注入），任何比例都没有统计意义，但方向值得注意：
这两条注入的写法跟 deepset 完全不同族。

**5. XSTest / AEGIS 全良性，所以 TPR 是 n/a。**
不是没跑，是这个集合里没有正样本。它们只回答一个问题：会不会把正常内容判成攻击。

## 若干必须写进论文的限定

- **PINT 只有 8 条**（Lakera 正式数据在 HF 上不可达，GitHub 只有示例文件）。
  表里这一列只能当冒烟，不能当结论。
- **ToxicChat 的注入只有 70 条**，TPR 的 95% 置信区间大约 ±11 个点，
  检测器之间 0.20 / 0.30 / 0.34 / 0.50 的差要谨慎解读。
- **WildGuardMix 因 gated 未纳入**（需要登录 HF 同意条款）。
- 目标集只做了去重，**没有做配平**——真实世界的先验不该被我们改掉。
- 源域数据里含 `synth` 合成样本，A2 的源域因此有一份合成成分，需在论文注明。
