# A4 攻击谱系 × 检测器：谁能扛住"被人针对"

> 代码：`injlab/eval/a4.py`（编排）+ `injlab/_a4_one.py`（单检测器矩阵）+ `injlab/attacks/semantic.py`（语义改写与多轮）
> 复现：`python -m injlab a4`
> 原始数据：`runs/20261101_231043_a4/a4.json`

## 一句话结论

**三个 TF-IDF 检测器被"全角化"一击全灭（ASR 1.000），而按字符扰动优化出来的
神经模型一个都没漏；但换成语义改写，局面反过来——现成 guardrail 被改写打穿 43.8%，
TF-IDF 反而纹丝不动。没有一种检测器对所有攻击族都硬。**

这句话就是本文为什么必须做**谱系**而不是单点评测的理由：只看一种攻击，
得到的排序会完全相反。

guardrail 上分轮 0.294 < 拼接 0.529：把三轮拼成一段反而**更容易漏**。
机制是长文本稀释——一句载荷塞进一大段话里，模型的注意力被摊薄。
这条对"多轮对话防御"的直接含义是：**别把历史拼成一坨去检测**。

## 四个值得单独写进论文的观察

**1. 全角化是"单点必杀"。**
把 ASCII 转全角（`ａ` 替代 `a`），三个 TF-IDF 检测器的 ASR 全部变成 1.000。
它们的分词表里根本没有全角字符，整个词对不上，检测直接归零。
缓解方案便宜得离谱：检测前做一次 `NFKC` 归一化（`injlab/eval/intent.py:canonicalize`）。
**这类攻击不是"检测器不够强"，是"没做输入规范化"**——工程疏漏而非模型缺陷。

**2. 神经模型的优势是"字符级不变性"，不是"更懂语义"。**
guardrail / distilbert 在全角、零宽、同形字上全部 ASR = 0。
它们在预训练时见过这些字符变体，子词切分把 `ａｔｔａｃｋｅｒ` 切回了可识别的片段。

**3. 但语义改写把局势反转了。**
`paraphrase` 对 guardrail 的 ASR\* 是 0.438（字面 0.622）——这是本次实验里
guardrail 唯一被打穿的地方。改写做了三件事：换同义词、重排句序、**把载荷包装成
一份"文档摘录"**（`README excerpt` / `Note for the assistant:` / 项目符号列表）。
容器一换，它就不再像"指示"，而像"资料"。

TF-IDF 在这里反而免疫（ASR\* = 0.000），不是因为它聪明，是因为它看的是
**字符 n-gram 的分布**：改写只动了词，没动标点、大小写、列表符号这些结构线索。

**4. 反常识的一条：语义改写对字符级模型几乎无效。**
这说明"鲁棒性"不是一个标量。同一个模型可以在一族攻击下是钢筋水泥，
在另一族下面目全非。**任何"我们的检测器鲁棒性提升了 X%"的说法，
不指明攻击族就没有意义。**

## 必须承认的统计局限

- 测试集里**恶意样本只有 37 条**。ASR\* 的分母是"意图仍可读"的子集（14–17 条），
  相邻两档之间差 0.06 就只是一条样本的差别。**不要在小数点后第三位上做文章。**
- **`base64_wrap` 的 ASR\* 全为 n/a**：编码后文本里已经找不到可判读的祈使句，
  意图判据给不出结论（`n_valid = 0`）。这不是"检测器防住了"，是"攻击没成功"。
  字面 ASR 里 keyword 是 1.000，正说明这一类必须靠意图判据过滤，否则会虚报。
- **`n_unknown` 在混淆类上是 21/37**：这批恶意样本原文就没有线索词
  （多为 `synth` 生成的间接注入），判据对它们无话可说。结论只在剩下 16 条上成立。
- `paraphrase-light` 的 `n_valid` 只有 4：它只改匹配到同义词表的那几句，
  多数样本改写后与原文完全一致，被"没有产生变化"判为无效。
- 攻击构造用的是**规则改写，不是训练出来的攻击模型**（Q10 的决定）。
  好处是确定、可复现、零成本；代价是它打不过一个真正的 PAIR/GCG 攻击者。
  论文里必须写明这一点，并作为"未来工作"。
