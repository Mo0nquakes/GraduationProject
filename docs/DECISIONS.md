## 1. 目标集不配平，保留真实先验

**选择**：A2 的目标集（ToxicChat / XSTest / AEGIS / PINT）只做去重，不做类别配平。

**为什么**：配平是为了让指标好看，但会掩盖真正的问题——真实流量里良性占绝大多数。
DistilBERT 在 ToxicChat 上误报 79%，这个数字只有在**真实先验**下才有意义。
一旦配平成 50/50，这个 79% 会变成 90%+ 的"看起来还行"，等于自己骗自己。

**代价**：TPR 的分母很小（ToxicChat 只有 70 条注入），置信区间 ±11 个点。

**你要是想改**：加一列"配平后"的数放在附录，主表保持真实先验。我不建议换掉主表。

## 2. 主表用固定阈值，oracle 单列一表并标注"不可部署"

**选择**：TPR 主表一律用**源域训练集**标定的阈值；另出一张 oracle 表（在目标域重标阈值）。

**为什么**：oracle 阈值是作弊——真实部署时你拿不到目标域的标注。
但它有用：**它能区分"阈值错位"和"排序本身就错"**。
A2 里 DistilBERT 的 oracle TPR 跟固定阈值 TPR 一模一样（都 0.343），
这一条直接证明了问题不在阈值，在模型把域外良性排在了注入前面。
没有这张表，你没法反驳"你只是阈值没调好"。

**代价**：多一张表，读者可能误读。所以表头必须写"不可部署"。

## 3. 语义改写用规则实现，不接 LLM API

**选择**：`paraphrase` 用同义词表 + 句序重排 + 文档化包装，纯离线确定性实现；
LLM 改写（`LLMRewriter`）留在代码里但默认不启用，需要 `INJLAB_LLM_BASE_URL`。

**为什么**：你没有 API key，我也不该在深夜替你去申请一个。规则版的好处是
**可复现、零成本、每条改动都能解释**；坏处是它打不过真正的 PAIR/GCG 攻击者。

**代价**：审稿人会说"你的语义攻击太弱"。所以论文里要明确写这是
**受控的下界**——"在这么弱的改写下 guardrail 已经掉了 43.8%，真实攻击只会更糟"。

**你要是想改**：填 `INJLAB_LLM_BASE_URL` / `INJLAB_LLM_MODEL` 就能切到 LLM 后端，
代码路径已经写好了（`injlab/attacks/semantic.py:LLMRewriter`），不需要改调用方。

## 4. sklearn 族不参与 A3，并把"做不了"写成结论

**选择**：A3 只有 DistilBERT 的三个变体；TF-IDF / 关键词模型不进 A3。

**为什么**：FGSM 要求对输入求梯度。词袋模型没有可微的输入表示——
换一个词是离散跳变，梯度不存在。**这不是"没做"，是"做不了"**，
而这个"做不了"恰好是你原开题里"传统 ML vs 预训练模型对抗鲁棒性对比"这一条不成立的原因。

**代价**：A3 只有一行对照，看起来单薄。但它换来一条方法学结论，值得。

## 5. A3 加了 `fgsm-weak`（ε=0.01）变体

**选择**：除了 ε=0.05，再跑一版 ε=0.01。

**为什么**：首跑 ε=0.05 时干净 TPR 从 0.973 塌到 0.027，第一反应是"你 eps 太大把模型打坏了"。
加一版弱扰动，无论它是不是也塌，都能回答这个质疑——如果弱扰动下 TPR 恢复、
ASR 仍然不降，那结论更硬；如果弱扰动下也塌，说明**这个方法在文本检测器上本身就
没法用**，结论更狠。

**代价**：多跑 3 次（每次约 2 分钟）。

## 7. 每轮回路最多并入 200 条

**代价**：这个数是拍的，论文里必须写成超参并做一次敏感性说明（时间不够就写"未做敏感性分析"，

**选择**：A1/A2/A3/A4/A5 全部用子进程（`injlab/_aX_one.py`），串行执行。

## 12. 难负样本用模板构造，不用从公开语料筛

**选了什么**：`injlab/data/hardneg.py` 用 14 条模板 × 五类语用（引用/提问/文档/代码/测试）生成 120 条难负样本。

**为什么**：先试过从 XSTest/AEGIS/ToxicChat 里筛"含线索词的良性样本"，得到 114 条，人工看了一批——相当一部分本身就是越狱提示（`[IGNORE ALL PREVIOUS]SYSTEM COMMAND ...`）。把它们标成良性等于给模型喂错标签，而"难负样本"实验的全部意义就在于标签干净。

**代价**：外部效度弱于真实采集，只覆盖五类语用；论文里必须写明，并补一句"真实世界'引用攻击串'的写法会更花"。

**怎么推翻**：做一次人工标注的真实难负集（200 条，双人标注 + 仲裁），和构造集对比 A6 结论是否成立。

## 13. A6 加第三臂（去线索词的对照组）

**选了什么**：三臂，而不是原始的"含 / 不含"两臂。

**为什么**：两臂没法回答"会不会只是数据变多了"。第三臂用同一批句子、同长度、同语用，只把线索词换成中性说法，`含难负 − 对照组` 才是真正的"难"效应。

**代价**：多跑一倍时间（约 6 分钟）。

**结果**：这个设计立刻体现出价值——DistilBERT 的 FPR 改善几乎全部来自对照组（加良性数据的量），只有召回提升来自"难"。两臂设计会把这个区别抹平。

## 14. A6 的阈值只取"源域训练集干净良性"

**选了什么**：三臂共用同一个阈值来源，不随训练集变化。

**为什么**：如果"含难负"臂用"训练集全部良性（含难负）"标阈值，阈值会被推高、误报率自动变好看——那是在比较两个工作点，不是在比较模型。

**代价**：某些臂的工作点不是最优的（比如含难负臂的阈值偏保守）。

**怎么推翻**：同时在附录报一版"各自最优阈值"的数字，标明不可部署。

## 15. A7 的结局拆成五态，"误报挡下"单列

**选了什么**：`leaked / blocked_poison / blocked_fp / not_leaked / missed` 五态，只有 `leaked` 进 ASR。

**为什么**：第一版把"任一文档超阈值"当作拦截，结果「仅检测」对全角攻击 ASR=0.00，看起来完美防御。翻明细才发现全角中毒文档只拿 0.15 分，根本没被检出；是旁边的良性制度文档拿 0.65 分被拦，整轮对话被连坐拦下。**这是"用误报冒充检出"，是安全评测里最典型的自欺。**

**代价**：表格列数变多，读起来更累。

## 16. A7 的靶子换成 `CompliantLLM`

**选了什么**：写一个比 `FakeLLM` 更容易服从的假模型。

**为什么**：`FakeLLM` 只认 `attacker@example.com` 这个字面串。语义改写把邮箱一换，它就"读不懂"，报告里显示成"攻击没成功"——其实是靶子太笨，不是防御有效。`CompliantLLM` 的服从条件是"上下文里出现任意邮箱 / api key + 发送类动词 / 覆盖指令"。

**代价**：仍然不是真模型，ASR 只能当上界读。

## 17. 截断攻击演示失败后，改做长度扫描

**选了什么**：A7 的 `--neural-truncation` 除了截断表，再输出一张"良性文本拼接 × 词数 → 分数"的扫描表。

**为什么**：截断攻击在 DistilBERT 上根本演示不出来——朴素推理在长文档上也是 1.00 检出。查下去发现：纯良性文本拼到 187 词就有 0.875 分，363 词时载荷与无载荷**同分**。源语料良性样本平均只有 10.5 词，模型学成了"长 = 可疑"。

**代价**：多写 40 行代码、多一次模型加载（约 15 秒）。

**收益**：这比截断攻击本身重要——它同时解释了 A2 里 79% 的域外误报，把两个孤立现象合并成一个病根（训练分布太短）。

## 18. 难负样本与 length bias 的关系先写进"未来工作"，不连夜补实验

**选了什么**：A7 里定位到"模型拿长度当特征"，但**没有**立刻做"把长良性文档加进训练集"的对照实验。

**为什么**：现在是凌晨，做完这个对照要重训 DistilBERT（约 5 分钟）× 训练集两种版本 × 3 种子 ≈ 40 分钟，而且它不在用户点名的 A1–A7 里。写清楚病根 + 给出可执行的修复实验，比连夜抢一个单种子的数字更有价值。
