## 1. 目标集不配平，保留真实先验

**选择**：A2 的目标集（ToxicChat / XSTest / AEGIS / PINT）只做去重，不做类别配平。

**为什么**：配平是为了让指标好看，但会掩盖真正的问题——真实流量里良性占绝大多数。
DistilBERT 在 ToxicChat 上误报 79%，这个数字只有在**真实先验**下才有意义。
一旦配平成 50/50，这个 79% 会变成 90%+ 的"看起来还行"，等于自己骗自己。

**代价**：TPR 的分母很小（ToxicChat 只有 70 条注入），置信区间 ±11 个点。

**你要是想改**：加一列"配平后"的数放在附录，主表保持真实先验。我不建议换掉主表。

---

## 2. 主表用固定阈值，oracle 单列一表并标注"不可部署"

**选择**：TPR 主表一律用**源域训练集**标定的阈值；另出一张 oracle 表（在目标域重标阈值）。

**为什么**：oracle 阈值是作弊——真实部署时你拿不到目标域的标注。
但它有用：**它能区分"阈值错位"和"排序本身就错"**。
A2 里 DistilBERT 的 oracle TPR 跟固定阈值 TPR 一模一样（都 0.343），
这一条直接证明了问题不在阈值，在模型把域外良性排在了注入前面。
没有这张表，你没法反驳"你只是阈值没调好"。

**代价**：多一张表，读者可能误读。所以表头必须写"不可部署"。

---

## 3. 语义改写用规则实现，不接 LLM API

**选择**：`paraphrase` 用同义词表 + 句序重排 + 文档化包装，纯离线确定性实现；
LLM 改写（`LLMRewriter`）留在代码里但默认不启用，需要 `INJLAB_LLM_BASE_URL`。

**为什么**：你没有 API key，我也不该在深夜替你去申请一个。规则版的好处是
**可复现、零成本、每条改动都能解释**；坏处是它打不过真正的 PAIR/GCG 攻击者。

**代价**：审稿人会说"你的语义攻击太弱"。所以论文里要明确写这是
**受控的下界**——"在这么弱的改写下 guardrail 已经掉了 43.8%，真实攻击只会更糟"。

**你要是想改**：填 `INJLAB_LLM_BASE_URL` / `INJLAB_LLM_MODEL` 就能切到 LLM 后端，
代码路径已经写好了（`injlab/attacks/semantic.py:LLMRewriter`），不需要改调用方。

## 4. sklearn 族不参与 A3，并把"做不了"写成结论

**选择**：A3 只有 DistilBERT 的三个变体；TF-IDF / 关键词模型不进 A3。

**为什么**：FGSM 要求对输入求梯度。词袋模型没有可微的输入表示——
换一个词是离散跳变，梯度不存在。**这不是"没做"，是"做不了"**，
而这个"做不了"恰好是你原开题里"传统 ML vs 预训练模型对抗鲁棒性对比"这一条不成立的原因。

**代价**：A3 只有一行对照，看起来单薄。但它换来一条方法学结论，值得。

---

## 5. A3 加了 `fgsm-weak`（ε=0.01）变体

**选择**：除了 ε=0.05，再跑一版 ε=0.01。

**为什么**：首跑 ε=0.05 时干净 TPR 从 0.973 塌到 0.027，第一反应是"你 eps 太大把模型打坏了"。
加一版弱扰动，无论它是不是也塌，都能回答这个质疑——如果弱扰动下 TPR 恢复、
ASR 仍然不降，那结论更硬；如果弱扰动下也塌，说明**这个方法在文本检测器上本身就
没法用**，结论更狠。

**代价**：多跑 3 次（每次约 2 分钟）。

## 6. A5 留出 `paraphrase` 与 `homoglyph` 两个攻击族

**选择**：训练只并 `paraphrase-light` / `fullwidth` / `zero_width`；
`paraphrase` 和 `homoglyph` **全程不参与训练**。

**为什么**：不留出的话，"回路训练后 ASR 降了"只能说明模型背下了见过的答案。
留出族是实验成立的前提，不是可选项。

**代价**：留出族的表现会比较差。那正是要报告的。

---

## 7. 每轮回路最多并入 200 条

**选择**：`max_aug=200`，经验值。

**为什么**：并入太多，模型的分布会被攻击样本主导，干净 TPR 会掉；
并入太少，看不出提升。200 是"能看出趋势又不至于把模型带偏"的折中。

**代价**：这个数是拍的，论文里必须写成超参并做一次敏感性说明（时间不够就写"未做敏感性分析"，
这比假装调过要诚实）。

---

## 8. 所有神经模型一个进程只加载一个

**选择**：A1/A2/A3/A4/A5 全部用子进程（`injlab/_aX_one.py`），串行执行。

**为什么**：你这台是 8GB 内存的 M2 Air，guardrail + distilbert 同进程会直接把整机拖死
（上次就是这么死的）。子进程退出即回收，峰值内存 = 最大单模型。

**代价**：每换一个检测器要重新加载模型（guardrail 约 10 秒）。
总时长比并行长，但换来的是"你的电脑还能用"。

## 9. 温度/超参一律按"最有利于被检验的方法"取

**选择**：A3 的 eps / steps / mix 都取了文献里常见的、对 AT 有利的设置。

**为什么**：这样结论被推翻的风险最小。如果在对它有利的设置下它仍然失败，
那这个负结果才站得住。
