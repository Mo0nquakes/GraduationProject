# 威胁模型（Threat Model）

> 这份文档是毕设的"网安内核"。它回答一个问题：**你到底在防谁、防什么、凭什么说防住了**。
> 没有它，检测器只是一个分类器实验；有了它，才是一篇安全方向的论文。
> 论文第 3 章可直接以本节为骨架展开。

## 1. 资产（Assets）

| 编号 | 资产 | 被攻破的后果 |
|---|---|---|
| A1 | 系统提示词 / 开发者指令 | 泄露业务规则、可被逆向用于更精准的攻击 |
| A2 | 会话上下文中的用户隐私 | 数据泄露，合规事故 |
| A3 | 模型可调用的工具与凭据（邮件、文件、支付） | **间接注入的真正目标**：越权动作 |
| A4 | 下游输出的可信度 | 用户被误导、钓鱼内容被"官方"口吻转发 |

## 2. 信任边界（Trust Boundaries）

```
用户输入 ──[边界1]──> 应用/编排层 ──[边界2]──> 检索到的外部文档
                                        └──[边界3]──> 工具返回结果
                                        └──[边界4]──> 模型输出 ──> 用户
```

关键认知：**边界 2、3 上的内容从来不是"可信数据"**。它们由第三方写入，
却和你的指令拼在同一个 prompt 里，模型没有"数据 vs 指令"的类型系统。
这正是间接提示注入（Greshake et al., 2023, arXiv:2302.12173）的根本困难。

## 3. 攻击者能力（Attacker Capabilities）

| 编号 | 攻击者类型 | 能力假设 | 是否在本文范围 |
|---|---|---|---|
| T1 | 恶意终端用户 | 可任意构造输入，无模型内部信息（黑盒），可无限次查询 | 是 |
| T2 | 内容投毒者 | 可让一条文档进入检索库/网页被爬取，不知模型权重 | 是（本文重点） |
| T3 | 有预算的优化攻击者 | 黑盒，但可用 LLM 迭代改写（PAIR / Crescendo 类） | 是（有限预算） |
| T4 | 白盒攻击者 | 知道权重与梯度，可做 GCG / FGSM | 仅作对照（说明其与 T1–T3 的差距） |
| T5 | 供应链攻击者 | 篡改模型权重或训练数据 | 否，列为未来工作 |

**必须写清的一句话**：真实世界的注入攻击几乎都是 T1–T3（黑盒、文本空间）。
所以只在 embedding 空间做 FGSM 对抗训练，防的是一个现实中不存在的攻击者。

## 4. 攻击面（Attack Surface）

| 面 | 载体 | 典型手法 | 对应实验 |
|---|---|---|---|
| S1 | 用户输入 | 指令覆盖、角色扮演、编码混淆 | A1 / A4 |
| S2 | 检索文档 | 隐藏 HTML 注释、白字、末尾追加指令 | A4 / A7 |
| S3 | 长文档 | 载荷放在 512 token 之外，利用截断 | A4（截断攻击） |
| S4 | 多轮对话 | 分步诱导，单轮看起来都无害 | 本文不覆盖，未来工作 |
| S5 | 工具返回 | 搜索结果里夹带指令 | 仅 RAG 靶子近似模拟 |

## 5. 防御者假设（Defender Assumptions）

- 防御者**不修改**被保护的 LLM 权重（那是模型厂商的事），只能在外围加检测/过滤。
- 防御者可以拿到一批标注数据，但**拿不到攻击者的完整攻击分布**。
- 延迟预算：单次检测 P99 < 100 ms（在线 guardrail 的现实约束）。
- 误报预算：FPR ≤ 1%（否则用户会直接关掉这个功能）。

## 6. 不在范围内（Out of Scope）

- 越狱（jailbreak）与注入的边界划分：本文把"让模型突破自身安全策略"归为越狱，
  只处理"让模型违背**应用方**设定的指令"，两者在数据上会有交叠，需在论文中说明。
- 多模态注入（图片内嵌文字）。
- Agent 工具链的权限最小化（CaMeL 类系统级方案），仅在相关工作讨论。

## 7. 安全论证（Security Argument）——答辩必问

> "你怎么证明你的系统是安全的？"

标准答案是**不证明**，而是给出可度量的风险降低：

1. 在固定 FPR（1%）下，报告 TPR 与各攻击族的 ASR（含置信区间）。
2. 报告**端到端** ASR：不是"检测器判对了吗"，而是"密钥泄露出去了吗"。
3. 报告攻击者**迭代对抗**后的性能衰减曲线（红队回路），而不是单轮快照。
4. 明确列出仍然有效的攻击（本文预期：强语义改写 + 多轮），
   并说明为什么当前方案防不住 —— 这比"我们的方法很有效"更有学术价值。
